# 📚 Resources & Further Reading

A curated collection of resources for diving deeper into Ethereum, smart contract development, and the topics covered in the workshop.

---

## Ethereum Fundamentals

| Resource | Description |
|----------|-------------|
| [ethereum.org](https://ethereum.org) | Official Ethereum website with guides, docs, and learning paths |
| [Ethereum Whitepaper](https://ethereum.org/en/whitepaper/) | Vitalik Buterin's original vision for Ethereum |
| [Ethereum Yellow Paper](https://ethereum.github.io/yellowpaper/paper.pdf) | Formal specification of the Ethereum protocol |
| [Ethereum Roadmap](https://ethereum.org/en/roadmap/) | Current development priorities and upcoming upgrades |
| [EIP Repository](https://eips.ethereum.org/) | All Ethereum Improvement Proposals |

## Learning Solidity

| Resource | Description | Level |
|----------|-------------|-------|
| [Solidity Docs](https://docs.soliditylang.org/) | Official language documentation | All |

| [Cyfrin Updraft](https://updraft.cyfrin.io/) | Free comprehensive smart contract course | Beginner to Advanced |
| [Alchemy University](https://www.alchemy.com/university) | Full-stack Web3 development course | Intermediate |
| [Speedrun Ethereum](https://speedrunethereum.com/) | Build and deploy 5 projects to learn Ethereum | Intermediate |
